# Voiceover & caption script

**You do not need to speak English on camera.** Two ways to use this file:

- **Captions only** — paste each line as on-screen text at the timestamp shown
- **AI voiceover** — paste each line into CapCut's *Text to speech*, which reads it in a
  natural English voice

Either way, the English the client hears is Aria's, and it is already perfect.

---

## How to use CapCut Text to speech (5 minutes)

1. Import your screen recording into **CapCut**
2. Tap **Text → Add text**, paste one line from the table below
3. Position it at the timestamp shown, set duration to about 3 seconds
4. With the text selected, tap **Text to speech** → choose a voice
   (**"Chill"**, **"Presenter"** or **"News"** sound most professional)
5. Repeat for each line
6. Lower the original call audio to about 60% wherever narration plays, so both are audible
7. Export 1080p

Voice suggestion: pick one **female English voice** and use it for every line. Switching
voices mid-video sounds amateurish.

## If you would rather write it in your own words

Keep these three rules and the English will read as natural:

1. **Short sentences.** Under ten words. Long sentences are where non-native English
   goes wrong, and where listeners stop paying attention.
2. **No filler.** Cut "as you can see", "basically", "so now what happens is".
3. **Numbers land hardest.** "Ninety seconds. Six cents." beats any adjective.
